# Droplet calculations and supplementary figure reproduction

- [Droplet calculations](droplet_analysis/README.md) contains two R scripts for the droplet fusion and condensate state models and the plotting workflow for Supplementary Figs. S1 and S2.
- [Supplementary figures](figure_reproduction/README.md) regenerates Supplementary Figs. S1–S5 from saved results. Its README lists the required R packages and the command used to generate the figures.
